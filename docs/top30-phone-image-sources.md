Tavily Extract supports candidate discovery through `include_images=True`. Tavily leaves permission for third-party content to the user and rights holder. The repository's QuickCommerce adapter uses product data for identity and price observations. Its current normalized output has no image import or license field. Cuelinks' documented publisher API provides links and offers and has no merchant product feed. An image URL requires asset-specific hosting or display rights before it enters the verified photo manifest.

The illustrative assets appear in research card HTML. Generic front views do not qualify as exact-product images for a Merchant Center product feed.
