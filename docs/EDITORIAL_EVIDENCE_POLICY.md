# Coupon World evidence and recommendation policy

## Publication rules
1. Preserve exact brand, model, India market and RAM/storage variant. Never merge conflicting regional variants.
2. Every factual specification used in a comparison must carry a source URL where available; mark absent values **Not confirmed**, never zero.
3. Manufacturer product pages and support documents are primary evidence for declared specifications. Manufacturer marketing claims are not independent benchmarks.
4. Independent hands-on performance claims require a named publication, test methodology, date and link. Coupon World must not claim to have personally tested hardware it has not tested.
5. Do not infer camera, gaming, battery or reliability winners from isolated specification values. A shortlist based on evidence coverage is **not** a performance ranking.
6. Recommendations must apply the requested budget and variant constraints before ranking. Unknown or dated prices must not be represented as live offers.
7. For comparisons, display differences and trade-offs without a winner if comparable independent evidence is insufficient.
8. Never fabricate product photography or substitute an image of another model. An image placeholder is preferable to incorrect imagery.
9. Record verified date, source URL, variant identity and evidence status for every material correction.
10. Search and filters must be tested against inclusive/exclusive budget boundaries, variant identity, Hindi/Hinglish aliases, exclusion terms and duplicate model IDs.

## Release checklist
- [ ] Run static SEO gate and all existing test suites
- [ ] Validate sitemap URLs against actual deployed routes; remove stale URLs only after checking redirects and backlinks
- [ ] Confirm canonical tags, robots policy, status codes and server-rendered content on production
- [ ] Test comparison of 1, 2 and 3 phones including missing specifications and unsafe source URLs
- [ ] Verify source links, labels, keyboard navigation and responsive tables
- [ ] Test no results, timeout, offline, and backend error states
- [ ] Verify recommendations never claim hands-on testing without evidence
- [ ] Check Search Console indexing, query impressions and click-through trends after deployment

## Scope
This policy does not establish that any particular model has been independently tested or that any recommendation is currently eligible.
